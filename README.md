# AI Assistant

This is a simple web-based AI Assistant built using Flask and OpenAI's GPT-3.5-turbo model. The assistant performs various tasks such as answering factual questions, summarizing text, and generating creative content based on user input.

## Features

- **Answer Questions**: Ask factual questions and get precise responses.
- **Summarize Text**: Provide a block of text and receive a concise summary.
- **Generate Creative Content**: Generate creative content such as stories or poems based on your prompts.
- **User Feedback**: Provide feedback on responses to help refine future answers.

```bash
python app.py
```

# How it works 

## Answer Questions
- Users can input factual questions (e.g., "What is the capital of France?"), 
- and the AI Assistant will respond with accurate information.

## Summarize Text
- Paste any block of text, and the assistant will generate a concise summary.

## Generate Creative Content
- Provide prompts for stories or poems, and the AI will generate creative outputs.

## User Feedback
- After each response, users are asked to provide feedback on whether the response was helpful or not.
